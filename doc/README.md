# 文档导航

这个目录按“读者视角”拆成了几份文档，避免把所有内容都堆在一份手册里。

## 推荐阅读顺序

1. `doc/USER_MANUAL.md`
2. `doc/API_OVERVIEW.md`
3. `doc/MIGRATION_GUIDE.md`
4. `PLAN.md`
5. `EXEC.md`

## 文档说明

- `doc/USER_MANUAL.md`：面向首次使用者，介绍项目定位、快速启动、基础概念、常见使用方式
- `doc/API_OVERVIEW.md`：面向开发者，按模块梳理核心 API、常见对象、示例与最佳实践
- `doc/MIGRATION_GUIDE.md`：面向迁移场景，说明 JBox2D / Box2D 到 KBox2D 的映射关系、迁移顺序与注意事项
